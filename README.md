# Front

Front de Schub, la boîte à outils de la communauté Miam : React + Vite + MUI.

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

## Build production

```bash
npm run build
```

## Preview locale du build

```bash
npm run preview
```
